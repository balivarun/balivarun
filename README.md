### 🏛️ [Civis](https://github.com/balivarun) — Civic Issue Reporting Platform
> React · Spring Boot · PostgreSQL · JWT · Spring Security · JUnit 5

Multi-user civic complaint portal with role-based dashboards (Citizens & Admins), real-time status tracking, image upload, and geo-location. Secured with JWT auth and tested with JUnit 5 + Mockito.

---

### 🛒 [ShopSphere](https://github.com/balivarun) — Full-Stack E-Commerce Platform
> Next.js 16 · TypeScript · Spring Boot · MongoDB · Razorpay · JWT

Multi-role e-commerce platform with Razorpay payment gateway (webhooks + signature verification), real-time email notifications via Spring Mail, and concurrent buyer/admin session support.

---

### 🤖 [YouTube-Auto](https://github.com/balivarun) — AI Hand Gesture Controller
> Python · OpenCV · NumPy · pynput · Computer Vision

Real-time hand-gesture recognition system using HSV skin-color detection and contour analysis. Classifies 4 gestures and maps them to media commands — achieving **sub-100ms response latency** via NumPy vectorisation.
